# 연도별 분석 화면 구현·검증

2026-10-17 · Yunze #23 · 가상 자료를 사용하는 화면 개발 범위

## 동작과 기준

결과 가까이의 여섯 번째 탭에서 연도별 키워드·사례·전망 작성 틀을 읽는다. 처음 진입하면 사업에 기록된 `completion_date`를 전체 조회 기준으로 적용한다. 이후 선택한 날짜 기준은 다른 탭으로 이동해도 유지된다. 연도별 화면에서 조건 초기화·새 자료 불러오기를 하면 준공일 기준으로 시작한다.

- 기본 집계 단위는 고유 설계사업이다. 학교 개교일·당선일·건물별 준공일로 사업 준공일을 추정하지 않는다. 여러 건물의 대표 준공연도 생성 규칙은 아직 추가하지 않았다.
- 공모·당선·기사 기준을 고르면 전체 화면과 내보내기도 같은 기준으로 바뀐다. 기사 연도는 조회 기간 안의 최초 연결 기사 날짜에 따라 배정한다.
- 살펴볼 연도는 이 패널의 표시만 바꾼다. 전체 기간의 사업 내보내기는 그대로라는 안내를 표시한다.
- 공통 주제 사전·중복 태그·미분류·출처 규칙을 사용한다. 완전한 직전 연도와 비교하며, 일부 기간이나 자료 없는 연도는 연간 증감을 제시하지 않는다. 5건 미만은 작은 표본 안내를 보이며 유의성 기준으로 사용하지 않는다.
- 사례는 기준 날짜 최신순으로 최대 3건이다. 통계적 대표 표본으로 표현하지 않는다. 허용된 이미지·직접 제작 개념도만 표시하고 상세의 주제 근거·출처와 연결한다.
- 전망은 작성·검토 대기다. 현재 주제에 연결된 검토 질문, 필요한 근거, 가정, 대안 설명, 검토자·검토일의 빈 상태를 보여준다. 실제 추세 해석이나 자동 예측을 생성하지 않는다.

실제 자료의 분류 정의·대표 준공연도·전망 근거와 검토 체계는 Daniel과 후속으로 합의해야 한다. 가상 사업 006~011에 추가한 준공일은 오직 화면 검증용이며 그 사실을 자료의 한계에 명시했다.

## 자동 검사

전체 `npm test` 139개 통과. 연도 도메인 11개와 UI–데이터 연결 4개를 추가했다.

- 준공일 기준 6건, 날짜 미확인 6건. 2024년 1건 / 2025년 2건 / 2026년 3건.
- 기본 당선일 기준은 기존 11건을 유지한다.
- 날짜 기준 4종 × 검색·지역·학교급·기간·주제 조건 8조합에서 연도별 합계, 화면 고유 사업 수, 내보내기 행 수가 일치한다.
- 중복·미분류·복수 태그·출처·기사 연도 귀속·연도 경계·부분 기간·전망 대기 상태를 검증했다.

## 실제 브라우저 확인

- 첫 진입: 공통 날짜 기준 `completion_date`, 화면·내보내기 6건, 연도 선택 2026년 3건.
- 2025년: 2024년과 비교 +1건, 키워드 분모·비율·작은 표본 안내. 2026년은 일부 기간으로 비교 보류.
- 2023년: 0건과 자료 대기. 연도만 바꿔도 전체 기간 다운로드 6건은 유지.
- 대표 이미지에서 내부 상세 열림, 준공일·기준 날짜·키워드 근거 확인, Escape 닫기.
- 당선일 변경 시 전체 11건으로 동기화하고 다른 탭을 거쳐 돌아와도 유지. 날짜 선택 초점 복원.
- 초기화 시 준공일 6건으로 복귀. 실제 CSV 다운로드를 파싱하여 6행, 준공 기준, 미확인 6건, 원본 준공일 보존 확인.
- 준공일이 없는 A1 가상 자료 가져오기: 0건·날짜 미확인 9건·자료 대기. 당선일로 대신 채우지 않음.
- CSS 너비 400px: 마지막 탭 접근 가능. 2025 비교표는 내부 650px 표만 가로 스크롤하고 페이지 너비는 380px로 유지. 발견한 그리드 최소 너비 문제를 수정 후 재확인.
- CSS 768px·800px에서도 상단 메뉴와 페이지 가로 넘침 없음. 정상 흐름의 브라우저 오류 로그 없음.

에이전트의 코드·브라우저 검증이며 팀원의 직접 승인 리뷰를 대신하지 않는다.
