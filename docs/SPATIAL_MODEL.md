# 키워드와 연결되는 학교 공간 개념도

이슈 #31의 첫 서비스 연결 범위다. 2026-10-19 작성. 실제 학교를 재현한 모델이 아니라 **같은 가상 학교에서 세 키워드의 공간 구성을 비교하는 설명 도구**다.

## 보는 방법

연도별 분석 또는 사례 상세에서 **키워드를 공간으로 이해하기**를 펼친다. 외부학습공간은 중정·학습 데크, 지역공유는 별도 진입부가 있는 도서관, 가변학습공간은 이동식 구획을 둔 학습 공용동을 강조한다. 노란 점과 이름표로 위치를 표시한다.

- 회전·확대 슬라이더는 마우스·터치와 키보드 방향키로 조작한다.
- 처음에는 **전체 외관**을 불투명하게 보여 준다. **내부 투과** 슬라이더를 0–100%로 높이면 앞쪽 도서관·학습 공용동의 지붕과 앞벽이 연속적으로 옅어진다. 뒤쪽 교사동과 중정은 유지하여 전체 형태를 잃지 않는다.
- **전체 외관**은 투과율 0%, 기본 각도·확대율로 돌아간다. **내부 보기**는 현재 시점을 유지하면서 두 앞쪽 동의 지붕·앞벽을 숨긴다. **시점 초기화**는 회전과 확대율만 되돌린다.
- 키워드 변경은 학교 형태·시점·확대율·투과율을 유지한다. 투과 슬라이더는 터치·마우스뿐 아니라 Tab과 방향키로 조작하며 현재 비율을 표시한다.
- 자동 회전은 없다. 그림 대신 공간 설명을 펼쳐 같은 내용을 읽을 수 있다.
- **보고서용 개념도 저장 (SVG)**에는 현재 시점과 키워드뿐 아니라 모델 성격·제작자·형상 출처·이용 조건·자료 범위·근거 출처·가정이 들어간다. SVG의 metadata에도 원래 식별자와 연결 정보를 보존한다.

## 관측과 공간 해석의 경계

`renderSpatialModel(container, {projects, snapshot, onOpenProject, selectedTopic, scopeLabel})`에 부모 화면이 전달한 사업만 근거 사례로 사용한다. `snapshot.projects` 전체에서 다른 연도·지역의 사례를 보충하지 않는다. 연도 화면은 해당 연도의 `project_ids`에 해당하는 전체 사업을, 사례 상세는 해당 사업 하나를 전달한다.

키워드와 같은 `topic_evidence`만 읽고 해당 `source_id`를 출처 목록에 대조한다. 출처가 없으면 연결 미확인, 안전한 원문 URL이 없으면 원문 링크 없음으로 표시한다. 알려진 출처 레코드가 있다는 것과 실제 내용의 검토 완료는 구분한다. 분류·출처의 검토 상태를 그대로 표시한다. 관련 키워드가 없는 조건에는 근거 사례 없음과 개념 설명임을 함께 표시한다.

근거 사례는 앞의 3건을 먼저 표시하고 나머지는 펼침 목록에 둔다. 전체 건수·저장 이미지의 연결 정보에는 모든 해당 사례를 포함하며 펼침 여부로 자료를 제외하지 않는다.

근거는 **사업의 키워드 분류에 대한 근거**이며 가상 모델의 치수·재료·배치에 대한 도면 근거가 아니다. 그림은 집계 건수·분모·사업 내보내기 결과를 바꾸지 않는다. 미래 가정 시나리오나 실제 건물 모델로 표시하지 않으며 학습·에너지·안전 성능을 수치로 추정하지 않는다.

## 구현과 성능

`src/ui/spatial-geometry.js`에 별도 개념 모델 메타데이터와 형상 규칙을 둔다. 공통 Snapshot에 새 필드를 추가하지 않았다. 단위는 설명용 모델 단위이며 검증된 미터 치수가 아니다. ㄷ자 교사동, 창호, 학습 데크, 계단 좌석, 도서관, 학습 공용동, 조경을 실제 3차원 꼭짓점으로 만들고 정렬·투영하여 SVG로 그린다.

패널을 처음 펼칠 때 형상을 만든다. 회전·확대·투과·키워드 입력에만 다시 그린다. 외부 라이브러리·텍스처·모델 다운로드, WebGL, 애니메이션 루프, AI 호출이 없다. 정적 SVG이므로 그래픽 장치 기능에 의존하지 않는다. SVG 파싱 실패에는 텍스트 대안을 남기고 저장 실패는 화면에 알린다. 외부 출처 링크는 HTTP(S)만 허용하고 인증정보가 있는 URL을 거부한다. 화면 문자열은 텍스트 노드, SVG 메타데이터는 XML 이스케이프를 사용한다.

2026-10-19 외관 개선에서 화면 투영과 깊이 정렬의 카메라 축을 직교하도록 맞추고, 지면을 건물보다 먼저 그리도록 분리했다. 기존에는 지면의 평균 깊이로 정렬해 뒤쪽 건물이 지면에 가려질 수 있었다. 보이지 않는 뒷면도 제외한다. 부분 투과는 지정한 외피에만 적용하고, 저장 SVG에도 같은 투과율·시점과 모델 설명을 넣는다. 이미지 전체를 흐리게 만들지 않는다.

모델을 표시하는 화면에서 같은 컨테이너를 재사용하면 로컬 시점과 선택을 유지한다. 반환된 `setTopic(topicId)`로 해당 보고서 키워드와 연결할 수 있다. `destroy()`는 이후 모델 갱신을 중지한다. 컨테이너를 다시 렌더링할 때 이전 인스턴스는 중지된다. 실시간 렌더링 작업이나 GPU 자원이 없어 별도 자원 해제는 필요하지 않다.

## 검증과 남은 범위

`tests/ui/spatial-model.test.js`의 15개 테스트는 필터 밖 근거 유입 방지, 키워드별 출처 일치, 중복 사업·출처 미확인·비정상 입력, 안전한 URL, 유한 3D 좌표, 투과 범위와 회전·확대, 키워드 변경 시 동일 형상 유지, SVG 저장 정보·문자열 삽입 방지·접근성 식별자를 점검한다. 추가 회귀 검사는 기본 불투명 외관, 50% 투과 시 외피만 변경, 지면이 건물을 덮지 않는 순서, 여섯 회전 각도의 지붕·교사동 표시, 카메라 축의 직교성을 확인한다. 서비스 연결 후 브라우저에서 실제 연도 선택·사례 상세·모바일·키보드·저장 기능을 확인한다.

도구에 실제 자료 자동 수집, AI 추가 학습, 사진 기반 복원, 치수 도면·IFC 변환을 연결한 것은 아니다. 더 사실적인 실제 학교 모델에는 사용권을 확인한 도면/IFC와 검증된 치수, 출처별 가정 기록이 필요하다. 모델·코드에 공개 라이선스를 새로 부여하지 않았으며 외부 재사용 조건은 팀의 라이선스 결정 뒤 정리한다.
