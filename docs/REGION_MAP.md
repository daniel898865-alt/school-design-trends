# 시도 경계 지도와 지역 정보 팝업

갱신일: 2026-10-17. [화면 개발 이슈 #29](https://github.com/yunzecho-eng/school-design-trends/issues/29)의 구현 범위다. 기존 #22의 개략도 선택 기능을 행정경계 자료 기반 지도와 마우스·키보드 정보 팝업으로 확장한다.

## 지도 기준과 표시 범위

지도는 **2026-04-01 기준의 17개 시도 경계 자료**로 만든다. 경계 위에 마우스를 올리거나 키보드로 이동하면 지역 이름과 현재 조회 조건의 수집 사례 수를 확인할 수 있다. 클릭하면 해당 지역의 사례·그래프·표·내보내기에 같은 시도 조건이 적용된다.

원자료는 SGIS 경계를 가공한 `vuski/admdongkor`의 `ver20260401/HangJeongDong_ver20260401.geojson`이다. 행정동 도형을 시도 단위로 합친 뒤 화면용 경계로 변환한다. 원본의 고정 커밋, 출처 표시·이용 조건, 시도 코드 대응, 단순화·투영 방법과 파일 해시는 [지도 자료 출처와 변환 기록](MAP_SOURCE.md)에서 관리한다.

현재 사업 집계는 17개 지역 분류를 사용한다. 이 기준과 비교할 수 있도록 지도 기준일도 고정했으며, **2026년 7월 이후 자료의 행정구역 개편은 반영하지 않았다.** 현행 최신 행정구역을 보여 주는 지도라고 해석하지 않는다. 경계 기준일과 사업 자료의 조회 기준일은 서로 다른 정보다.

지형은 고정된 SVG 표시 영역 안에서 같은 투영과 배율을 사용한다. 화면이 좁아져도 가로·세로를 따로 늘리지 않고 비율을 유지한다. 지역 선택은 시도 경계 도형을 따르며, 지도 위의 지역 이름을 클릭해도 그 이름의 지역을 선택한다. 작은 구역을 누르기 어려우면 지도 아래 이름 버튼으로 선택한다.

행정경계 자료를 사용하는 것과 실제 학교 설계사업을 수집하는 것은 별개다. 현재 사례 수는 가상 자료의 조회 결과이며, 지도는 학교별 좌표·정밀 측량·법적 경계 판정 기능을 제공하지 않는다. 도형의 화면 면적이나 길이로 실제 지역 면적·거리를 비교하지 않는다.

## 마우스·키보드·모바일 사용법

1. 시도 경계 위에 마우스를 올리면 지역 이름과 `수집 사례 N건` 또는 `집계 미제공` 팝업이 열린다. 마우스를 올리는 것만으로 조회 조건을 바꾸지는 않는다.
2. 경계를 클릭하면 해당 시도가 선택된다. `Tab`으로 경계에 초점을 이동해 같은 정보를 읽고 `Enter` 또는 `Space`로 선택할 수도 있다.
3. `Escape`로 팝업을 닫는다. 다른 지역으로 이동하면 그 지역 정보를 다시 확인할 수 있다. 팝업 안으로 마우스를 옮겨 내용을 읽는 동안 바로 사라지지 않도록 처리한다.
4. 작은 구역이나 터치 화면에서는 **지역 이름으로 선택**을 펼쳐 17개 시도 버튼을 이용한다. 이 버튼들은 최소 44px 이상의 누름 영역을 갖는다. SVG의 작은 시도 경계 자체가 모두 44px 이상인 것은 아니다.
5. **전체 시도**는 지역 조건을 해제한다. **지역 미확인**은 위치를 추정하지 않은 자료만 선택한다. 상단의 기존 시도 선택 상자도 그대로 사용할 수 있다.

선택한 지역은 초록색·체크 표시·선택 안내 문장으로 표시한다. 마우스 미리보기와 키보드 초점에도 별도 강조를 제공한다. **색의 진하기는 건수를 나타내지 않는다.**

## 숫자와 미확인 상태

- 숫자는 공통 자료 모듈의 `byRegion`이 제공한 수집 사례 건수다. 지도에는 지역 조건만 해제하고 검색어·학교급·기간·날짜·주제를 유지한 결과를 전달한다. 선택하지 않은 지역의 건수도 계속 비교할 수 있으며, 아래 그래프·사례·내보내기에는 선택 지역까지 적용한다. 지도에서 사업 건수를 다시 계산하지 않는다.
- 명시된 `0`은 `0건`으로 표시한다. 이는 현재 조건에 맞는 수집 사례가 없다는 뜻이며 해당 지역 전체에 설계사업이 없다는 뜻이 아니다.
- 지역 행이 없거나 건수가 `null`, 음수, 문자열, 소수 등 유효하지 않으면 `미제공`으로 표시한다. 같은 지역 행이 두 번 전달된 경우도 임의로 합치지 않는다.
- 지역 미확인 자료에는 경계나 대표 위치를 임의로 배정하지 않는다.
- 다지역 사업은 각 해당 시도에 참여할 수 있으므로 시도별 숫자의 합이 전체 고유 사업 수와 다를 수 있다. 전체 버튼에는 지역 숫자를 임의로 합산한 전국 건수를 붙이지 않는다.

## 코드와 접근성 연결

`renderRegionMap(container, { regions, selectedRegion, onSelect })`를 호출한다.

`regions`는 `[{ code, label, count }]`, `selectedRegion`은 공통 시도 코드·`unknown`·빈 문자열이다. 시도 코드와 정식 이름은 `src/data/normalize.js`의 `REGIONS`를 따른다. 원본 경계 자료의 코드 대응은 [자료 변환 기록](MAP_SOURCE.md)에 명시하며, UI에서 별도 사업 분류를 만들지 않는다.

`onSelect(code)`는 앱의 시도 선택 값을 바꾼 뒤 기존 필터·집계·내보내기 흐름을 실행한다. 전체 선택은 빈 문자열로 전달한다. 화면을 다시 그린 뒤에는 원래 사용한 경계 또는 이름 버튼으로 초점을 돌려놓고 페이지를 자동 스크롤하지 않는다. 이름 버튼 목록을 펼친 상태도 유지한다.

시도별 SVG 그룹은 `role="button"`, `tabindex="0"`, `aria-pressed`와 지역 이름·건수를 담은 접근성 이름을 갖는다. 열린 팝업은 `role="tooltip"`과 `aria-describedby`로 해당 경계에 연결한다. 선택 안내는 `aria-live="polite"`로 전달한다. 지도 아래 시도 목록, 전체·미확인 선택은 네이티브 HTML 버튼이다.

## 검증 결과 · 2026-10-17

전체 자동 테스트 **147개 통과**. 그중 경계 검증 6개와 지도 집계·팝업 위치 검증 8개가 포함된다. `node tools/build-region-geometry.mjs --check`도 통과했다. 새 경계의 라벨 기준점 17개는 각각 자기 지역 도형 내부에 있고 다른 시도와 중복 포함되지 않음을 별도 확인했다.

- `tests/ui/region-map.test.js`: 17개 시도·미확인 처리, 0과 미제공 구분, 잘못되거나 중복된 집계행, 입력 불변성, 팝업 위치의 표시 영역 제한.
- `tests/ui/region-geometry.test.js`와 자료 생성 검증: 시도 코드 대응, 유효한 경계, 투영·종횡비와 재생성 일치. 상세 검증 방법은 [출처 문서](MAP_SOURCE.md)를 따른다.
- 실제 브라우저: 서울 라벨 클릭(3건), 강원 경계 클릭(0건), 세종 Enter(0건), 제주 Space(2건), Tab 이동·Escape 닫기와 재렌더 후 초점 복원 확인. 키보드 선택 시 정지한 마우스 아래의 다른 구역 정보로 바뀌던 문제를 수정하고 재확인했다.
- 필터 연동: 서울 선택 시 오른쪽 지역명·사업 수·학교급(초등 2건, 고등 1건)·사례 3건과 내보내기 3건이 일치했다. 실제 내려받은 CSV의 사업 3행도 모두 서울이었다. 지역 미확인 0건, 전체 해제 11건을 확인했다. 오른쪽 사례 제목의 내부 상세와 Escape 후 원래 제목으로 초점 복귀도 확인했다.
- 반응형: CSS viewport 320·1099px에서 한 열, 1100·1200px에서 두 열을 확인했다. 각 너비에서 문서 가로 넘침이 없고 팝업이 지도 안에 남았다. 320px의 목록 버튼 17개는 최소 너비 약 48.3px·높이 48px였다.
- 결과 바로가기: 모바일에서도 오른쪽 결과 영역에 실제 초점이 이동하고 결과 시작점이 고정 탭 아래에 남았다(시작 120.2px, 탭 하단 109.7px). 콘솔 오류·경고는 없었다.

단순 포인터 이동만 수행하는 자동화 기능이 없어 hover 유지·팝업 위로 포인터 이동·지도 밖에 초점이 있을 때 Escape 동작은 코드 검토로 보완했다. 포인터 클릭으로 진입하는 동작과 키보드 팝업은 실제 브라우저에서 확인했다. 화면 읽기 프로그램과 모든 모바일 기기에서의 직접 검증은 수행하지 않았다.

## 지역 선택과 결과 배치

[이슈 #28](https://github.com/yunzecho-eng/school-design-trends/issues/28)은 전체 이슈 병합 요청에 따라 이번 작업 범위에 포함했다. 넓은 화면은 지도 왼쪽·선택 지역 결과 오른쪽, 좁은 화면은 지도 다음 결과 순서로 배치한다. 기존 공통 필터·고유 사업 집계·내보내기 범위는 그대로 사용한다.

실제 학교 사례 수집, 새 행정구역 기준으로의 집계 전환, 월별 자료 갱신은 별도 범위다.
