# 시도 선택 개략도

작성일: 2026-10-17. 화면 개발 이슈 #22의 범위다.

## 표시 범위와 읽는 법

이 화면은 **위치 이해를 돕는 개략도이며 실제 행정경계가 아니다.** 대한민국 본토와 제주를 연한 도형으로 직접 그린 뒤, 17개 시도 선택 버튼을 대략적인 상대 위치에 배치했다. SVG 경로와 CSS 배치는 이 프로젝트에서 직접 작성했다. 외부 지도 이미지·행정경계 파일·타일을 내려받거나 윤곽을 추적하여 복제하지 않았다.

수도권·광역시·세종은 좁은 화면에서도 누르기 쉽도록 간격을 넓혔다. 도형의 면적·거리·해안선·생략된 섬은 실제 지리 정보나 관할권의 표현이 아니다. 측량, 경계 판정, 위치 좌표의 입력 등에 사용하지 않는다. 정밀 지도 기능을 추가하려면 별도로 이용 조건과 좌표계가 확인된 경계 자료를 확보해야 한다.

시도 코드와 정식 이름은 `src/data/normalize.js`의 `REGIONS`를 사용한다. 표시 순서와 17개 시도·지역 미확인 항목은 공통 데이터 규격을 따른다. 강원·전북의 현재 코드와 이전 코드 변환은 공통 정규화 모듈의 책임이며, 지도에서 새 변환 규칙을 만들지 않는다.

위 자료는 지역 설명 참고이며 SVG의 원본이나 경계 데이터 출처가 아니다. 제작 시 일부 상세 페이지의 직접 열람은 서버 오류로 제한되었고 검색 서비스가 반환한 공식 페이지 설명을 확인했다. 정밀 지도와의 경계 대조를 수행했다고 주장하지 않는다.

## 숫자와 미확인 상태

- 숫자는 공통 자료 모듈의 `byRegion`이 제공한 수집 사례 건수다. 지도에는 지역 조건만 해제하고 검색어·학교급·기간·날짜·주제를 유지한 결과를 전달한다. 다른 지역을 계속 선택할 수 있도록 선택하지 않은 지역의 건수도 보존하며, 아래 그래프·사례·내보내기에는 선택 지역까지 적용한다. 지도에서 집계를 다시 계산하지 않는다.
- 명시된 `0`은 `0건`으로 표시한다. 이는 현재 조건에 맞는 수집 사례가 없다는 뜻이며 지역 전체에 설계사업이 없다는 뜻이 아니다.
- 지역 행이 없거나 건수가 `null`, 음수, 문자열, 소수 등 유효하지 않으면 `미제공`으로 표시한다. 같은 지역 행이 두 번 전달된 경우도 임의로 합치지 않는다.
- 지역 미확인 자료는 위치를 추정하지 않고 별도 버튼으로 선택한다.
- 다지역 사업은 각 해당 시도에 표시될 수 있으므로 시도별 합계를 전국 고유 사업 수로 사용하지 않는다. 전체 버튼에도 임의 합산한 전국 숫자를 붙이지 않는다.
- 색은 **선택 여부만** 나타낸다. 건수에 따른 색 농도나 전국 분포 추정은 제공하지 않는다.

## 접근성과 연동

`renderRegionMap(container, { regions, selectedRegion, onSelect })`를 호출한다.

`regions`는 `[{ code, label, count }]`, `selectedRegion`은 공통 시도 코드·`unknown`·빈 문자열이다. `onSelect(code)`는 앱의 시도 선택 값을 바꾼 뒤 기존 필터·집계·내보내기 흐름을 다시 실행한다. 전체 선택은 빈 문자열로 전달한다.

17개 시도, 지역 미확인, 전체 선택 모두 네이티브 HTML 버튼이다. Tab으로 이동하고 Enter 또는 Space로 선택한다. 선택 상태는 `aria-pressed`, 텍스트와 체크 표시로 함께 제공한다. 콜백이 화면을 다시 그려도 동일한 `data-region` 버튼으로 초점을 복원하며 페이지를 자동 스크롤하지 않는다. 상단 시도 선택 상자도 그대로 사용할 수 있다.

버튼은 좁은 화면에서도 최소 44px 이상의 누름 영역을 유지한다. 바탕 SVG는 장식용으로 처리하고, 스크린리더에는 정식 시도 이름과 건수를 버튼 이름으로 제공한다.

## 검증

`node --test tests/ui/region-map.test.js`는 17개 시도 누락, 미확인 지역, 0과 결측 구분, 잘못된 건수, 중복 집계행, 미지원 코드, 입력 불변성을 확인한다. 클릭·키보드·모바일 배치는 통합 화면에서 별도로 확인한다.

2026-10-17 통합 확인: 기본 가상 자료의 전체 11건에서 서울 선택 시 화면·내보내기 3건, 부산을 Enter로 선택 시 2건, 지역 미확인 선택 시 0건, 전체 해제 시 11건을 확인했다. 서울 선택 후에도 부산의 지도 건수 2건이 유지된다. 재렌더 후 선택 버튼으로 초점이 돌아오며, CSS 화면 너비 400px에서 페이지 가로 넘침 없이 모든 시도 버튼이 60×48px로 표시된다. 지도 전용 6개를 포함해 연도별 기능을 제외한 기존 검사 124개가 통과했다.
