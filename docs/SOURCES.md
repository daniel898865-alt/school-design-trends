# 수집 출처 후보와 확인 상태

확인일: 2026-10-17. 아래는 출처 조사 결과이며 API 연동·크롤링·전국 수집이 완료됐다는 뜻이 아니다.

| 출처 | 활용 목적 | 현재 확인한 범위 | 다음 확인 |
|---|---|---|---|
| [월간 SPACE](https://vmspace.com/main/main.html) | 건축 사례·설계 설명·공모 관련 뉴스 탐색 | 잡지·뉴스 페이지 존재 | 학교 사례의 범위, 수집 방법, 요약·이미지 이용 조건 |
| [PROJECT SEOUL](https://project.seoul.go.kr/main/viewMain.do) | 서울시 공모·당선 발표 확인 | 공모·아카이브·뉴스와 RSS 안내 존재 | 학교 대상 포함 여부·조회 범위·RSS 필드; 전국 대표로 사용하지 않음 |
| 각 시도교육청 공고·당선 발표 | 학교 설계공모와 공식 당선 결과 | 기관별 상세 URL 목록은 미확정 | 먼저 1~2개 교육청의 10~20건을 수작업 대조하고 확장 |
| [조달청 나라장터 낙찰정보서비스](https://www.data.go.kr/data/15129397/openapi.do) | 공고·계약 관련 결과의 보조 확인 | 공식 데이터 안내 페이지 확인 | 이용 신청·인증·학교 설계용역 식별 필드·사무소 식별자 제공 범위. 낙찰을 설계공모 당선과 동일시하지 않음 |
| [학교알리미 API 안내](https://www.schoolinfo.go.kr/ng/go/pnnggo_a01_m0.do) | 학교·학교급·지역·공시정보 연결 | 인증키와 공시 항목별 가이드 이용 절차 확인 | 학교 식별자·사용 조건·정확한 시설 항목. 전국 건물별 준공일 제공 여부는 미확인 |
| [학교알리미 주요지표 공개 자료](https://www.data.go.kr/data/15129917/fileData.do) | 초기 CSV 수동 입력 경로 검토 | 학교급·시도교육청·공시연도별 공개용 자료 안내 확인 | 필요한 필드와 자료별 이용 조건; '시설 정보 있음'을 동별 준공일 확보로 해석하지 않음 |
| 교육청 건물대장·공개 시설현황 | 40년 이상 건물의 준공일 근거 | 전국 초중고 동별 공개 원장은 아직 확보하지 않음 | 건물 ID·준공일·철거/개축 상태·자료 기준일·이용 조건 |
| 사무소 공식 홈페이지·공식 당선/계약 자료 | 사무소명·공동 당선·공개 사업자번호 확인 | 개별 사무소 확인은 아직 수행하지 않음 | 같은 이름의 업체 구분, 공개 번호와 법인/상호의 대응 |

잡지·뉴스는 사례를 발견하는 경로로 쓰고, 공모 당선 사실은 가능한 한 발주기관 발표로 확인한다. 언론 보도 시점은 설계·당선·준공 시점과 다르다. 동일 프로젝트의 여러 보도를 별도 사업으로 세지 않는다.

**노후 건물 목록의 선행 과제:** 학교 기본정보의 개교일이나 유치원 한정 건축연도 자료로 전국 초중고 건물의 연령을 대신 계산할 수 없다. 필요한 동별 공개 자료를 확보하지 못하면 확인된 지역·학교만 표시하고 커버리지를 공개한다.

자료별로 원문 URL, 발행일, 수집일, 자료 기준일, 제공기관, 이용 조건을 남긴다. 처음에는 수동 입력으로 시작하고 제공 API/RSS/공개 다운로드를 우선 검토한다. 자동 수집 가능 여부와 빈도는 출처별로 확인한다. 접근 제한을 우회하거나 실제 인증키를 공개 저장소에 기록하지 않는다.
