## 반영 범위

- 작품집 입력 166건을 기본 화면에 연결하고 가상 예시와 구분한다. Snapshot 0.1/0.2를 읽고 수록연도 확장 필드를 검증한다.
- 수록연도와 실제 당선일·준공일을 구분한다. `award_year` 조회는 연 단위이며 월별 빈도를 합성하지 않는다.
- 날짜·검색·지역·학교급·주제 조건의 사업 목록과 CSV/Markdown 목록을 일치시킨다.
- 사례 상세에 작품집 수치·설계자 표기·심사평 요지·쪽수·확인 메모를 표시한다.
- 연도별 키워드와 사례 상세에 선택형 공간 모델을 연결한다. 같은 가상 학교를 회전·확대·절개하고 키워드로 강조한다. SVG는 모델 성격·가정·출처·이용 조건을 포함한다.

## 발견하고 수정한 문제

1. `goe-2024-482` 평택교육지원청 청사는 원문 용도와 사업 내용이 충돌하지만 `middle`로 집계됐다. 학교급을 `unknown`으로 두고 원문은 `metrics.program`, 변경 이유는 `data_issues`에 보존했다. 중학교 32건, 미확인 10건이 된다.
2. 수록연도 조회가 음수·세 자리·다섯 자리 정수도 받았다. 자료 연도와 같은 1000–9999 범위를 적용했다.
3. 실제 자료를 데모 전용 화면 검사가 거부했다. 일반 Snapshot 검증과 가상 예시 전용 검증을 구분했다.
4. 실제 날짜가 없는 자료를 날짜 필터에 넣어 모두 제외했다. 수록연도 전용 조회를 추가했다.
5. 내보내기 출처 열의 ‘기사 수’를 ‘연결된 자료 수’로 고쳤다.

## 남아 있는 자료·운영 범위

- 일반 학교 외 특수학교·사택·유치원·교육시설이 섞인 경기도 작품집 당선작 표본이다. 전국 전체 사업·시장점유율로 해석하지 않는다.
- 2024년 주제 근거와 사무소 ID 연결이 비어 있다. 설계자 문자열은 상세·검색용이며 새 사무소로 자동 병합하지 않는다.
- 주제 근거 240개는 `draft_ai`. 학교급·수치·요약·심사평·쪽수는 사람의 원문 대조가 필요하다.
- 2023년 원문 URL이 없고 2025년 쪽수는 목차/본문 번호가 다를 수 있다. 귀속 미확인 심사평 두 건은 비워 둔다.
- 실제 도판·사진·도면은 포함하지 않는다. 공간 모델은 직접 작성한 설명용 형상이며 실제 학교 재현·BIM·성능 분석·미래 예측이 아니다.
- 자동 수집·재학습·도면 변환·월별 갱신·설명영상은 이번 통합에 포함하지 않는다.
