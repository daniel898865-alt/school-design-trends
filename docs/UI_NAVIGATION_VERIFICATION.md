# 사례 이미지와 결과 탭 검증

2026-10-17 · Yunze #20·#21 · `yunze/2026-10-17-case-navigation`

## 구현한 동작

- 결과 영역 위에 전체 동향·설계 사례·설계 사무소·건물 연령·설계 주제 탭을 배치했다. 현재 패널 하나만 같은 위치에 표시한다.
- 상단 메뉴는 해당 결과 탭으로 이동한다. 결과 탭은 스크롤 중 상단에 유지된다. 탭 전환 시 검색·지역·기간 조건과 카드/표 모드를 보존한다.
- 선택된 탭과 패널의 접근성 연결을 제공하고 좌우 방향키·Home·End를 지원한다. 일반 필터 재렌더링은 스크롤·포커스를 이동하지 않는다.
- 카드 썸네일·제목·상세 보기 버튼은 내부 상세를 연다. 원문 사이트는 별도 새 탭 링크다.
- 상세 이미지가 여러 개면 썸네일로 선택한다. 이미지별 제작자·이용 상태 기록·출처를 표시한다. 이미지 실패와 이용 조건 미확인은 대체 안내를 제공한다.
- 현재 가상 자료의 비어 있는 원문 URL은 그대로 둔다. 실제 학교나 임의 사이트를 사례 원문으로 붙이지 않았다.

## 확인 결과
