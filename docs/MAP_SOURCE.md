# 시도 경계 지도의 출처와 변환

확인일: 2026-10-17 · **경계 기준일: 2026-04-01**

현재 화면은 2026년 4월 1일의 **17개 시도 경계**를 사용합니다. 실제 경계 자료를 화면용으로 단순화한 것이며, 최신 행정구역을 자동 반영하는 지도는 아닙니다. 학교 사업은 여전히 별도의 가상 데이터입니다.

군위군은 선택한 원자료에서 8개 읍면 모두 `sido: "27"`, `sidonm: "대구광역시"`, 행정기관코드 `27720…`으로 확인했습니다. 강원·전북도 각각 특별자치도 코드 `51`, `52`로 제공됩니다.

## 경계 가공

Shapely **2.1.2**, GEOS **3.13.1**로 다음 순서를 수행했습니다. upstream 저장소의 실행 코드는 사용하지 않았습니다.

1. `sido`별 `union_all`로 행정동을 합쳐 시도 내부의 행정동 선을 제거했습니다. 합친 좌표는 150,609개입니다.
2. 시도 경계 전체를 교차점에서 나누고 `polygonize`로 면을 구성했습니다. 원자료의 극미세 겹침 면 5개는 원자료에 먼저 나온 지역에 배정했습니다. 인천·경기의 경계 차이로 생긴 수치 오차이며, 전체 정리 전후 대칭차 면적 합은 약 `2.059 × 10⁻¹⁰` 제곱도입니다. 이는 지표면 면적 단위가 아닙니다.
3. 정리한 17개 지형의 `coverage_is_valid`가 `True`인지 확인했습니다. 이 검사는 영역이 겹치지 않고 인접 경계의 꼭짓점이 서로 일치하는지 확인합니다.
4. `coverage_simplify(..., tolerance=0.002)`로 공유 경계를 함께 단순화했습니다. Visvalingam–Whyatt 방식이며 0.002도는 알고리즘 허용값이지 모든 점의 최대 거리 오차가 아닙니다. [알고리즘 설명](https://shapely.readthedocs.io/en/2.1.2/reference/shapely.coverage_simplify.html)
5. 단순화 후 17개 지형이 각각 유효하고 coverage도 유효함을 확인했습니다. polygon 요소는 전후 **1,115개로 동일**합니다. 섬을 임의로 삭제·이동·확대하지 않았습니다.

최종 파일은 `public/maps/south-korea-regions.geojson`입니다. 시도 내부의 구멍은 유지하고, SVG의 `fill-rule="evenodd"`로 해석합니다. 단순화로 세부 해안선과 작은 지형의 모양은 달라질 수 있습니다.

원본 전체와 중간 파일·일회 변환용 Python 의존성은 `.git/map-source-cache/`에만 두고 등록하지 않습니다. 일반적인 재생성에는 이 파일이나 Python이 필요하지 않습니다.

## 오프라인 SVG 재생성

```sh
node tools/build-region-geometry.mjs
node tools/build-region-geometry.mjs --check
```

생성기는 저장소 안의 시도 GeoJSON만 읽으며 네트워크와 외부 패키지를 사용하지 않습니다. 첫 명령은 모듈을 갱신하고 검증 보고서를 출력합니다. `--check`는 파일을 쓰지 않고 현재 모듈과 재생성 결과가 정확히 같은지 검사합니다. 입력·생성물의 LF 줄바꿈은 `.gitattributes`로 고정합니다.

경도·위도에 `u = longitude × cos(36°)`, `v = −latitude`를 적용한 다음 **한 개의 공통 배율**로 `viewBox="0 0 560 650"`에 맞춥니다. 최소 여백은 28입니다. 현재 실제 위아래 여백은 약 88.854입니다. 제주와 동쪽 섬을 같은 좌표계에 그대로 배치합니다.

- `KOREA_REGIONS`: `[{code, name, paths}]`, 17개 시도별 경로
- `KOREA_PATHS`: 호환용 전체 경로 배열; 시도 경계도 포함하므로 국가 외곽선만을 뜻하지 않습니다.
- `projectPoint(lon, lat)`: 지도와 동일한 투영을 적용하는 `{x, y}`
- `PROJECTION`: 영역, 원본 범위, 공통 배율과 이동량
- `GEOMETRY_SOURCE`: 경계 기준일, 분류 기준, 출처·라이선스·해시

SVG에는 `preserveAspectRatio="xMidYMid meet"`를 사용합니다. 최종 GeoJSON에서 SVG로 옮길 때는 좌표를 추가 삭제하지 않으며 SVG 좌표만 소수 셋째 자리로 반올림합니다.

## 해석의 한계

소축척 탐색용 경계이며 측량, 법적 경계 판정, 항해 또는 개별 학교 위치 확인에 사용하지 않습니다. 위도 36° 기준의 간단한 투영은 면적 보존 투영이 아닙니다. 화면의 면적·길이로 지역 크기나 거리를 계산하지 않습니다. 시도 표식은 대표 위치이지 학교 좌표가 아니며, 해당 지역에 사업 자료가 있다는 근거도 아닙니다.

국가 윤곽과 내부 경계를 다른 출처에서 겹쳐 그리지 않습니다. 현재 외곽선과 시도 경계는 모두 위의 동일한 원자료에서 가공했습니다.
