# 공통 데이터 연결과 웹 공개 검증

2026-10-17 · Yunze 이슈 #3·#12, Daniel A2 PR #14를 연결한 후속 작업이다.

온라인 화면: https://yunzecho-eng.github.io/school-design-trends/

## 구현

- `src/ui/data-provider.js`: A1의 입력 검증·중복 정규화·필터·집계, A2의 사무소·건물 연령·설계 주제·내보내기를 호출한다. UI에서 연령 공식이나 지역 집계를 별도로 계산하지 않는다.
- UI 단일 필터를 A1 배열형 필터로 변환하고 검색으로 좁힌 동일 Snapshot을 조회·내보내기에 사용한다. 주제 미분류는 A2 기준을 따른다.
- 기존 예시의 주제 ID 다섯 가지를 공통 사전에 명시적으로 연결한다. 원본 `_raw`는 보존하고 안내를 한 건으로 요약한다.
- 당선일·공모일·기사 게시일을 지원한다. 게시일의 ISO 시각은 A1에서 기재된 날짜로 처리하며, 여러 달에 게시된 같은 사업은 각 달에 포함될 수 있음을 표시한다.
- 여러 지역에 걸친 사업, 지역·사업유형 결측, 미등록 사무소와 근거 부족을 표시한다. 자료 기준일과 조회 기준일을 구분한다.
- 파서 오류가 있거나 첫 조회가 실패하면 자료를 교체하지 않는다. 이전 자료·필터·화면·내보내기를 유지한다. 경고는 화면의 확인 사항으로 제공한다.
- 공통 모듈·규칙 JSON만 로컬 서버 허용 경로에 추가했다. `.git`, `.env`, 허용하지 않은 규칙 파일은 404다.
- GitHub Pages는 `main`의 루트에서 HTML을 제공한다. `.nojekyll`로 정적 파일을 제공하며 홈페이지 링크를 저장소 About과 README에 등록했다.

## 범위와 한계

입력은 `is_demo: true`, 규격 v0.1인 가상 JSON만 지원한다. 실제 학교·업체 검증, 전국 자료 수집, 미래 전망, 월별 자동 갱신·이전 달 변화 비교는 제공하지 않는다. CSV 수식 처리는 문자열·브라우저 다운로드로 검증했으며 실제 Excel·Google Sheets 실행 검증은 아니다.

주제 정의는 팀 합의 전 초안이다. 사용 상태 미확인 건물도 준공 정보가 있으면 연령을 표시하고, 철거·폐교는 별도 표시한다. 연령은 안전등급을 뜻하지 않는다. 2월 29일의 평년 경계는 A2의 3월 1일 관례를 유지하며 법적 노후도 판정을 주장하지 않는다. 건물 전용 내보내기 함수는 A2에 있으나 화면 다운로드 버튼은 설계사업 목록용이다.
