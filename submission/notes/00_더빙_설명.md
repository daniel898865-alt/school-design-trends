# 더빙 영상 설명

- 최종 파일: `중간과제_소개영상_더빙.mp4` — 1920×1080, 약 177초(2분 57초), 5.9MB, H.264 영상 + AAC 음성(스테레오 48kHz).
- **음성은 본인이 직접 낭독해 녹음한 파일(`더빙\내_녹음\01~18.m4a`)입니다.** 음성 복제·합성은 쓰지 않았으므로 합성 음성 안내는 넣지 않았습니다. 수업 녹음본 등 다른 사람의 목소리는 쓰지 않았습니다.
- 원본 영상 `중간과제_소개영상_스크린샷기반.mp4`는 그대로 보존했습니다(133초, 음성 없음).
- 영상 상단에는 기존대로 "스크린샷 기반 소개 영상(실시간 화면 녹화 아님) · 사람 검수 전"이 표시됩니다.

## 만든 방법
- 장면 이미지(`원본_장면이미지`)를 그대로 쓰고, 녹음 길이에 맞춰 일부 장면을 늘렸습니다(원래 132초 → 177초). 새로 촬영하지 않았습니다.
- 녹음은 앞뒤 무음만 다듬고, 장면 간 음량을 비슷하게 맞췄습니다(클리핑 방지). 배경음악은 없습니다.
- 이 PC의 Edge(MediaRecorder)로 영상과 음성을 결합했고, 외부 서비스·설치·업로드는 없습니다. 확정 시간표는 `더빙\더빙_시간표_확정.json`, 도구는 `더빙\mux.mjs`입니다.
- 자막: 영상에 입혀진 기존 하단 자막(장면 요약)은 그대로이고, 낭독 대본 전문은 `자막_더빙.srt`(낭독 시간 기준)에 있습니다.

## 확인한 것
- 18개 장면 모두 음성 구간에서 소리가 있고(무음 장면 없음), 장면 사이 구간은 조용합니다. 장면 시작 시각에 맞춰 음성이 들어갑니다(결합 영상의 음성을 디코드해 시간표와 대조).
- 시작(2초)·중간(40초·90초)·끝(170초) 위치로 이동해 재생되고 화면 글씨가 읽혔습니다. 총 길이 177.4초, 음성 176.4초.
- 문장 끝이 잘리지 않았는지는 녹음 길이를 기준으로 앞뒤 0.12초 여유를 두어 자르지 않았고, 장면 길이를 녹음 길이에 맞춰 늘렸습니다. **귀로 직접 들어 보는 확인은 제가 할 수 없으니, 처음부터 끝까지 한 번 들어 보세요.**
