## 알아 둘 것
- 영상의 "커밋 3개·파일 15개"는 영상 제작 시점 값입니다. 이후 사용설명 커밋(`a1eeb75`)이 추가되어 현재 비교 링크는 그보다 많습니다.
- 팀원 PR 리뷰, 충돌 해결 PR, 다른 팀 PR 증빙은 확인된 기록이 없어 `notes/00_준비기록.md`에 미확인으로 적었습니다.
- 올리지 않은 것: 직접 낭독 녹음 원본, 기본 음성 파일, 장면 이미지 원본, 시험 입력 PDF와 중간 결과(비공개 폴더).
- 저장소를 GitHub Pages로 배포하므로 이 폴더의 파일도 배포 주소에서 내려받을 수 있습니다.
