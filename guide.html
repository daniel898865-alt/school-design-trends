개인 홈페이지 열기 · 웹 사용설명 열기

2026.10.20 기준. 경기도교육청 작품집 2023~2025 수록 당선작 166건을 사용하는 개인 고도화 도구입니다. 모든 자료·분석은 사람의 원문 검수 전입니다. 연도는 작품집 수록 기준이며 실제 당선일·준공일과 구분합니다.

1. 처음이라면: 예시 결과부터 보세요

홈페이지를 보는 데는 GitHub 로그인이나 프로그램 설치가 필요하지 않습니다.

  1. 상단 ③ 설계안 PDF 비교를 누릅니다.
  2. 시연 예시 보기를 누릅니다.
  3. 입력 조건 → 후보 선정 이유 → 공통 비교표 → 장점·운영상 부담 → 조건부 제안을 순서대로 봅니다.
  4. 위쪽 Markdown 보고서 저장 ↓ 또는 result.json 저장 ↓로 결과를 저장합니다.

이 예시는 공개 작품집의 동탄12고 8쪽 발췌본을 새 설계안이라고 가정한 시험 결과입니다. 버튼을 누르는 순간 PDF 분석을 새로 실행하는 방식은 아닙니다.

2. 네 가지 메뉴

메뉴할 수 있는 일읽을 때 주의할 점
① 연도별 동향시설 유형, 사업유형, 학교급, 규모 중앙값과 입력 정보의 범위를 확인전체 정량 집계와 5건의 정성 분석은 다른 범위입니다.
② 향후 설계 방향관찰·해석·적용 조건·반대 근거와 미확인 사항을 함께 확인미래를 확정하는 예측이 아니라 검토할 방향입니다.
③ 설계안 PDF 비교시연 결과 또는 Claude가 만든 내 result.json을 불러와 비교·저장홈페이지는 PDF를 분석하거나 AI를 호출하지 않습니다.
자료 조회기존 검색·지역·학교급·수록연도 필터, 사례 상세와 내보내기 사용기존 조회 기능을 그대로 이용하는 화면입니다.

3. 연도별 동향 읽기

  • 전체 수록 건수: 2023년 42건, 2024년 69건, 2025년 55건입니다.
  • 현재 school 분류의 집계 대상: 40건, 61건, 35건입니다. 유치원·특수학교·사택·청사 등은 별도 유형으로 구분합니다. 유치원·특수학교가 학교가 아니라는 뜻이 아닙니다.
  • 규모 중앙값: 값이 있는 사업만 계산하며 집계 건수와 정보 없음 건수를 함께 표시합니다. 누락된 값을 0으로 채우지 않습니다.
  • 2024년 태그·사무소 연결: 미부여(정보 없음)입니다. 해당 주제나 사무소가 실제로 없다는 뜻이 아닙니다.
  • 아래쪽 공간 전략: 전체 166건을 모두 도면 분석한 결과가 아니라 선택한 5건의 분석입니다.

사업유형의 장 구성이 연도별로 다르므로 다른 분류명을 임의로 합치지 않았습니다. 당선작 표본의 구성 차이를 연간 발주량, 실제 성능, 경기도 전체 설계 추세로 단정하지 않습니다.

4. 향후 설계 방향 읽기

각 카드의 네 항목을 함께 봅니다.

  1. 관찰한 내용: 어떤 사례의 글·도면에서 무엇을 읽었는가.
  2. 해석: 그 사실을 어떤 공간 전략으로 이해했는가.
  3. 적용 조건: 다른 설계안에 적용하려면 무엇을 확인해야 하는가.
  4. 반대 근거·미확인: 어떤 부분은 아직 판단할 수 없는가.

예를 들어 강당 볼륨이 구분돼 있어도 주민 이용과 학생 영역의 운영상 출입 통제가 확인된 것은 아닙니다. 장점만 가져오기보다 연결통로·관리 주체·개방 시간 같은 조건을 함께 살펴보세요.

5. 내 설계안 PDF를 비교하려면

A. Claude Code에서 분석

이 단계에는 Claude Code와 개인 프로젝트 폴더가 필요합니다. 홈페이지에서 PDF를 업로드해 분석하는 기능은 없습니다.

  1. Claude Code에서 이 저장소의 개인 프로젝트 폴더를 엽니다.
  2. 설계안 PDF를 data/private/design-research/my-school/input/design.pdf에 둡니다. 작업명과 파일명은 바꿀 수 있습니다.
  3. 다음 요청에서 PDF 경로와 목적을 본인 상황에 맞게 바꿔 보냅니다.
school-design-research 스킬로 설계안 PDF를 비교해 주세요.
PDF: data/private/design-research/my-school/input/design.pdf
목적: 주민 개방 영역과 학생 영역의 분리 방식 비교
사실 / AI 해석 / 제안을 구분하고,
후보를 고른 이유와 확인하지 못한 사항도 적어 주세요.
  1. Claude가 쪽 구성과 입력 조건을 읽고, 검색 도구로 후보를 찾은 뒤 필요한 근거를 확인합니다. 원문에 접근할 수 없거나 판독하지 못한 부분은 미확인으로 남깁니다.
  2. 완료하면 같은 작업 폴더의 report/result.json과 report/report.md 위치를 확인합니다.

사용자 PDF·추출 이미지·중간 결과·보고서는 기본적으로 Git 제외 폴더에 둡니다. 자동으로 GitHub에 올리지 않습니다. 다른 PC에서는 GitHub에 올리지 않은 이 파일들이 자동으로 나타나지 않습니다.

B. 홈페이지에서 결과 보기

  1. ③ 설계안 PDF 비교를 누릅니다.
  2. 내 result.json 불러오기를 누릅니다.
  3. 위에서 만든 report/result.json을 선택합니다. PDF나 임의로 만든 JSON을 선택하지 않습니다.
  4. 입력 조건, 후보와 선정 이유, 공통 비교표, 장점과 부담, 조건부 제안, 근거와 미확인 사항을 확인합니다.
  5. Markdown 보고서 저장 ↓, result.json 저장 ↓로 저장할 수 있습니다.

선택한 결과 파일은 브라우저 안에서 읽으며 외부로 전송하지 않습니다. 이는 홈페이지의 결과 불러오기 동작에 대한 설명이며, Claude Code의 PDF 분석 과정과는 구분합니다.

6. 결과에서 쓰는 말

표시뜻
부합확인한 자료에서 비교 조건에 대응하는 내용이 있음. 우수성·당선 가능성 점수가 아닙니다.
불일치반대되는 내용의 명시적 근거가 있음.
수치 차이면적·층수 등의 숫자가 다름. 필수조건이 없으면 곧바로 부적합이라고 판정하지 않습니다.
정보 없음미입력·언급 미확인·판독 불가 등으로 판단할 근거가 부족함. 실제로 없다는 뜻이 아닙니다.
사실 / AI 해석 / 제안자료에 적힌 내용, AI가 읽어 낸 전략, 적용 전 검토할 방향을 구분합니다.
새로 읽음 / 기존 분석 재사용이번 실행에서 직접 읽은 것과 이전 판독 기록을 재사용한 것을 구분합니다.
사람 검수 전AI의 분석 결과로, 사람이 원문과 대조해 검수 완료한 상태가 아닙니다.
중복 확인 필요이름·주소 등이 겹쳐도 별개 사업일 수 있으므로 같은 사업인지 추가로 확인해야 함.

Markdown(.md)는 글과 표로 된 보고서 파일이고, JSON(.json)은 홈페이지가 결과를 읽을 수 있도록 내용을 정해진 형식으로 담은 파일입니다.

7. 막힐 때

상황해 볼 일
PDF를 넣는 버튼이 안 보임정상입니다. PDF 분석은 Claude Code에서 하고, 홈페이지에는 result.json을 불러옵니다.
결과 파일에 오류가 뜸PDF 대신 올바른 result.json인지 확인합니다. 오류 문구를 Claude에 보여 주고 결과 파일의 형식을 고친 뒤 다시 선택합니다.
파일이 너무 크다고 나옴result.json은 최대 2MB입니다. 원문·이미지가 섞이지 않았는지 확인합니다.
파일을 잘못 골랐음오류 안내 후 정상 result.json을 다시 선택할 수 있습니다.
화면이 계속 불러오는 중임HTML 파일을 더블클릭하지 말고 공개 홈페이지 주소로 접속합니다. 로컬 사용자는 프로젝트에서 npm start를 실행합니다.
다른 PC에서 PDF나 보고서가 안 보임Git 제외 폴더의 로컬 파일은 자동으로 GitHub에 동기화되지 않습니다. 승인된 방법으로 별도 옮겨야 합니다.
결과가 예상과 다름출처 쪽, 입력 조건, 후보 이유, 정보 없음·판독 불확실 표시를 먼저 확인합니다.

8. 현재 범위와 한계

  • 대상은 경기도교육청 2023~2025 작품집 수록 당선작 166건입니다.
  • 정성 분석 사례는 5건이며 모두 사람 검수 전입니다.
  • PDF 시연은 공개 작품집 발췌를 시험 입력으로 사용했습니다. 새로운 사용자 설계안으로 시험한 기록은 아직 없습니다.
  • 시연 후보 2건의 단면·입면은 열람하지 않았습니다. 입력의 표고·연결통로 층수도 불확실한 부분이 있습니다.
  • 후보 검색의 키워드 일치는 요약·심사평의 단서이며 원문 검증 자체가 아닙니다.
  • 실제 운영 성과·교육 효과·에너지 성능·당선 가능성이나 미래 추세를 보증하지 않습니다.
  • 홈페이지에서 AI API를 호출하지 않습니다. Claude Code 분석은 별도 서비스 이용에 해당합니다.

개발자용 결과 형식과 명령은 DESIGN_RESEARCH.md, 분석 기준은 architecture-analysis.json에 있습니다.
